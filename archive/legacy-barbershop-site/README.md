# ארכיון – אתר המספרה המקורי

התוכן בתיקייה הזו הוא האתר המקורי של "רמי עיצוב שיער" (מספרה בירושלים, קביעת תורים בוואטסאפ).

הריפו הזה עבר **פיבוט מלא**: מאתר תדמית למספרה מקומית → מערכת אוטומטית לחנות דרופשיפינג מבוססת סוכני AI. הקבצים כאן נשמרו כארכיון היסטורי בלבד ואינם חלק פעיל מהפרויקט החדש.

התוכנית החדשה נמצאת ב-[`docs/`](../../docs) בשורש הריפו.
