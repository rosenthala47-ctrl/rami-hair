# חנות דרופשיפינג אוטומטית — מבוססת סוכני AI

> **פרויקט זה עבר פיבוט:** הריפו שימש בעבר לאתר תדמית של מספרה מקומית ("רמי עיצוב שיער"). התוכן ההוא נשמר לארכיון ב-[`archive/legacy-barbershop-site/`](archive/legacy-barbershop-site) והפרויקט הפעיל כעת הוא מערכת חנות דרופשיפינג אוטומטית ("Maximum Automation") המנוהלת ע"י רשת סוכני AI עצמאיים.

## עקרון העל

ה-AI מנהל תפעול, תוכן, שיווק ושירות לקוחות. התפקיד האנושי מצטמצם לנקודת אישור אחת: **תקציבים והחלטות פיננסיות/עסקיות**.
